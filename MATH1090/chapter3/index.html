    MATH1090 Introduction to Set Theory The integers

    Chapter 3¶

    1. Peano's axiom¶

    We say the triple data of \((N, 0, S)\) or just \(N\) for short is a model of the natural numbers if:

    1. If \(S(x)=S(y)\) for \(x,y\in N\), then \(x=y\) (\(S\) is injective).
    2. For all \(x \in N\), \(S(x)\neq x\) .
    3. There is no \(x\in N\) such that \(S(x)=0\).
    4. (Principle of Induction) Suppose a predicate \(P\) is true of \(0\), and that whatever \(P\) is true of \(x\), it is also true of \(S(x)\). Then \(P\) is true for all \(x\in N\).

    Exercise 3.1.1 Show that the set \(\{0,1,2\}\) with \(S(0)=1, S(1)=2, S(2)=0\) does not satisfy all Peano axioms. Which axioms fail?

    Solution

    The third axiom failed, there shouldn't be any \(S(x)=0\) but now we have \(S(2)=0\), contradiction.

    2. Defining arithmetic operations: \(+\) and \(\cdot\)¶

    First, we define \(+\):

    $$ \begin{cases} a+0=a\ a+S(b)=S(a+b) \end{cases} $$ and likewise with the order reversed.

    Exercise 3.2.1 Show that for all \(n\in N\), \(0+n=n\).

    Solution

    We shall prove this by induction.

    Let \(P(n)\) be the predicate \(0+n=n\).

    By defintion we have \(a+0=a\), substitute \(a=0\), we get \(0+0=0\), hence \(P(0)\) is true.

    Assume \(P(x)\) is true, i.e. \(0+x=x\),

    consider \(P(S(x))\),

    \[ \begin{aligned} 0+S(x) &= S(0+x) && \text{(by definition)} \\ &= S(x) && \text{(by induction assumption)} \end{aligned} \]

    Therefore \(P\) is also true of \(S(x)\).

    By the principle of induction, \(P\) is true of all \(n\in N\).
